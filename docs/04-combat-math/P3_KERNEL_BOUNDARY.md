# P3 kernel / P4 mathematics boundary

Status: ACCEPTED

P3 provides deterministic mechanisms.

P4 provides tuned equations and target bands.

## P3 may decide

- stat identity and runtime storage,
- modifier add/remove/order mechanics,
- resource storage/spend/gain/max-change mechanics,
- condition composition,
- effect execution order,
- aura lifecycle,
- event phases,
- cast lifecycle,
- cooldown mechanisms,
- target-legality hooks,
- server-authority boundaries.

## P3 must not freeze

- health by level,
- enemy health by level,
- attack/spell coefficients,
- armor/resistance curves,
- crit/hit/dodge/parry rates,
- haste equations,
- mana regeneration rates,
- resource generation rates,
- GCD duration,
- normal TTK,
- elite/boss scaling,
- XP pacing,
- item stat budgets.

Fixture numbers exist only to prove mechanisms.

They are not balance decisions.
