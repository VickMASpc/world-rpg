# Combat mathematics bible

Status: DRAFT

This document will become the exact mathematical specification for combat. Large combat content is blocked until baseline equations and resolution ordering exist.

Required sections include level health/resources, primary and derived stats, weapon/AP/SP scaling, armor, resistance, hit/miss/dodge/parry/block, criticals, level-difference penalties, haste/GCD, cast modification, DoT/HoT ticks, absorbs, mitigation order, resources, threat/taunt, crowd control, interrupts/school locks, elite/boss rules, pets, group scaling and rounding.

Every formula must define units, clamps, rounding and worked examples.

The same equations must be usable by headless simulation so tuning and regressions are testable outside Minecraft.
