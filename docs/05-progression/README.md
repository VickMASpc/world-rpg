# Progression bible

Status: DRAFT

Current planning target: 100 levels and roughly 350-500 hours for a blind first-character journey. This is a band to test, not yet a locked curve.

Progression dimensions include XP/level, class toolkit, talents, ability ranks, equipment, possible weapon skills, professions, reputation, travel network, world discovery, quest access, wealth and mounts.

For every level the final model should define expected cumulative hours, XP, XP/hour, normal enemy level and TTK, player health/damage baseline, gear band, wealth, trainer purchases, class unlocks, profession range and likely active regions.

Slow progression must emerge from meaningful play density and duration. XP curves cannot hide insufficient content.
