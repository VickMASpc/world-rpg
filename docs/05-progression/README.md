# Progression bible

Status: GROUNDED — DETAILED TABLES STILL DRAFT

The governing progression intent now lives in:

- `docs/00-constitution/PLAYER_LIFE_CYCLE.md`
- `docs/00-constitution/PROGRESSION_DOCTRINE.md`
- `docs/00-constitution/REWARD_DOCTRINE.md`

Core working target:

- 100 levels;
- roughly 350-500 hours for a blind first character;
- leveling is the game, not an extended tutorial;
- growth includes class/toolkit, gear, professions, reputation, travel network, wealth, world knowledge and access;
- scaling remains compressed enough that old gear/places age gradually rather than disappearing every few levels.

Future detailed tables may define cumulative hours, XP, enemy relationships, health/power bands, gear budgets, wealth, trainer purchases and profession ranges.

Those tables must implement the doctrine rather than redefine it.
