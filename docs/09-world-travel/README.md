# World and travel

Status: DRAFT

The main RPG land is fixed and authored. Procedural terrain is not the progression backbone.

Before large terrain production, define regions, subregions, level/threat bands, roads, rivers, passes, barriers, settlements, graveyards, dungeons, travel nodes and an approximate travel-time graph.

Current pacing intent to test: local objectives take minutes; settlement-to-settlement often 8-20 minutes; major-region traversal often 20-30 minutes; important first-time journeys 30-60+ minutes; expeditions 1-3 hours.

These are not quotas. Quiet terrain is valid.

Designed places receive stable IDs. Travel progression comes from discovered roads, inns, ferries, carriages, flight routes and eventually mounts rather than unrestricted map teleportation.
