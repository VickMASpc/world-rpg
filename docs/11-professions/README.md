# Professions

Status: DRAFT

Professions are long-duration parallel progression rather than a short checklist.

Exact profession roster is not frozen. Each profession eventually defines skill progression, trainers/tiers, recipe acquisition, level/region bands, resource inputs, outputs, economy interaction, rare recipes and validation against item/material registries.

Profession pacing must be simulated against the hundreds-of-hours character journey so it neither completes trivially nor becomes disconnected grind.
