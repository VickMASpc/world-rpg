# UI and UX system

Status: DRAFT

World RPG has enough interface surface to require a design system.

Major surfaces: HUD, player/target/cast frames, action bars, character/equipment, bags, spellbook, talents, quest log, dialogue, map/minimap, vendor/trainer/repair, professions, reputation, loot, death, travel, settings, character creation and developer inspection.

Shared design rules must cover typography, spacing, panels/borders, rarity/status colors, icon sizes, tooltip anatomy, focus/input, scrolling, scaling, layout and accessibility.

Native Minecraft Screen/DrawContext and candidate UI libraries will be prototyped before admitting a dependency. UI never owns gameplay truth.
