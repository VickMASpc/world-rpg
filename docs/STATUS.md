# Planning status

## Current phase

**Grounding pass inserted between the initial P2 foundation and further deep implementation.**

The existing P2 branch remains active, but implementation pauses after the staged content-transaction foundation while the experiential design is grounded.

## Completed implementation foundation

- Repository initialized.
- Fabric 1.21.1 shell created.
- Java 21 and split main/client sources established.
- CI working.
- Stable RPG IDs.
- Validation model.
- Immutable typed registries.
- JSON common content envelope.
- Typed references.
- Staged candidate content transaction.
- Atomic last-known-good publication.
- Initial tests.

## Grounding work now active

See:

- `docs/00-constitution/SPIRIT_OF_THE_GAME.md`
- `docs/00-constitution/GROUNDING_GATE.md`
- `docs/00-constitution/EXPERIENCE_LENSES.md`

The next work is experience definition, not more infrastructure.

## Blocked until grounding is mature enough

- deeper persistence implementation,
- Fabric resource adapter work beyond what is needed to validate design assumptions,
- mass ability/class implementation,
- mass items,
- quests,
- NPC population,
- mob catalogs,
- professions,
- terrain production,
- final UI,
- final balance numbers.

## Why

World RPG cannot be allowed to become a technically sophisticated but emotionally dead RPG.

The plant must remain subordinate to the lived-in world it is supposed to produce.
