# Architecture Decision Records

ADRs record durable choices that future implementation/content may depend on.

States: PROPOSED, ACCEPTED, SUPERSEDED, REJECTED.

Each ADR records context, decision, consequences, alternatives where useful, and revisit/migration triggers where relevant.

Do not rewrite history when a decision changes. Supersede the old ADR and link its replacement.

Initial accepted decisions:

- ADR-0001 — Freeze Minecraft at 1.21.1.
- ADR-0002 — Server-authoritative gameplay.
- ADR-0003 — Systems in code, game content in data.
- ADR-0004 — Stable namespaced identifiers.
- ADR-0005 — No general-purpose content scripting in core.
- ADR-0006 — Single runtime mod artifact initially.
- ADR-0007 — Static definitions separate from runtime state.
- ADR-0008 — External dependencies require explicit admission.
