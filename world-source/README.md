# Fixed-world source

The authored RPG world is a first-class project artifact.

This area will own source metadata and tooling inputs for continent topology, regions/subregions, roads/travel graph, semantic POIs, spawn areas, graveyards, transport nodes, discovery regions, world-state anchors and world package/version metadata.

Large binary world data may require a storage strategy outside ordinary Git history. That decision must be made before terrain production begins.
